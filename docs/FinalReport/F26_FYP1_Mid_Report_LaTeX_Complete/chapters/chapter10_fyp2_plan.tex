\chapter{FYP-2 Roadmap and Evaluation Plan}

\section{Completion Plan for Remaining FYP-1 Milestones}
Following the mid-assessment checkpoint, the team will complete the following FYP-1 milestones:
\begin{enumerate}
    \item \textbf{Slice C Completion (Weeks 9--11):}
    \begin{itemize}
        \item Finalize collusion detection algorithms for reciprocal ratings, temporal rating bursts, and retaliatory feedback following disputes.
        \item Remove expected failure scaffolding on scenarios ES-04 and ES-05, achieving 100\% pass rates across all 20 scenario fixtures.
    \end{itemize}
    \item \textbf{Human Moderation Workflow (Weeks 11--12):}
    \begin{itemize}
        \item Implement dispute initiation endpoints and contested return photo comparisons.
        \item Build the moderator review queue and adjudication interface on the Expo web client.
    \end{itemize}
    \item \textbf{Hosting and CD Rehearsal (Weeks 13--14):}
    \begin{itemize}
        \item Execute formal zero-downtime deployment and rollback rehearsals on the Render and Neon cloud infrastructure.
        \item Document deployment latency benchmarks and final system test runs.
    \end{itemize}
\end{enumerate}

\section{FYP-2 Strategic Roadmap}
In FYP-2, the platform will progress from an isolated technical core to a comprehensive community deployment:
\begin{enumerate}
    \item \textbf{Community Federation and Governance:} Implement multi-community isolation, role delegation for community elders/administrators, and custom safety policies per neighbourhood.
    \item \textbf{Advanced Verification Subsystems:} Expand locality verification from coarse polygons to privacy-preserving zero-knowledge proximity proofs or cryptographically signed local utility bills.
    \item \textbf{Asynchronous Notification Infrastructure:} Integrate WebSockets and push notifications for real-time transaction updates, inspection alerts, and moderator requests.
    \item \textbf{Item Condition Computer Vision Assistant:} Investigate on-device image comparison models to assist lenders and borrowers during handover and return condition verification.
\end{enumerate}

\section{Comprehensive Evaluation and Validation Plan}
The FYP-2 evaluation will adhere to strict empirical separation between synthetic simulation, public benchmark graphs, and real-world pilot trials:
\begin{itemize}
    \item \textbf{Algorithmic Performance \& Robustness:} Stress-test the assurance engine on the full synthetic scale tier (2,026 users, 10,000+ transactions), measuring runtime latency, memory consumption, and graph search scaling across varying $k$-hop depths.
    \item \textbf{Ablation Studies:} Quantify the marginal contribution of each engine component (direct Beta estimation alone, direct + similarity, direct + indirect, direct + collusion detection) to measure precision gains.
    \item \textbf{Controlled Neighbourhood Pilot Study:} Subject to institutional ethics clearance and participant consent, deploy Digital Mohalla within a designated residential enclave (30--50 households) for a four-week trial to collect qualitative usability and safety feedback.
\end{itemize}
